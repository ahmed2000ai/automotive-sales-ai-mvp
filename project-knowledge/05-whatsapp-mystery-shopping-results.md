- friendly personalized tone

  - gloss vs matte
- tailored package for Nissan Patrol
- price supplied
- financing supplied
- social proof supplied
- relevant Patrol example images supplied

- follow-up invited objection / modification rather than simply asking:
  - “still interested?”

### Missing / Weak

- installation duration from the original enquiry was not answered
- price required a second prompt from the customer

### Current Position

> **Strongest overall sales-process benchmark in the test so far.**

### Key Product Lesson

The problem is not that every business lacks good salespeople.

A better product thesis is:

> **Make every salesperson perform more consistently like the best salesperson, while AI ensures nothing gets missed.**

# 11. Cross-Business Pattern Analysis

The first cohort already shows multiple distinct problems.

## Pattern A - Context-Blind Automation

Observed in:

- DRIVEN
- Liquidglass automated layer

Symptoms:

- asks for information already supplied
- sends generic marketing material
- does not understand customer intent

---

## Pattern B - Question-Completion Failure

Observed across several businesses.

The standard enquiry asked for:

- price
- film
- warranty
- installation time

Yet multiple replies missed at least one.

Examples:

### KMQ

- price: yes
- film: yes
- warranty: yes
- installation time: **no**

### Superior Choice

- price: yes
- film: yes
- warranty: yes
- installation time: **no**

### Pro Master

- price: **not in captured response**
- film: yes
- warranty: yes
- installation time: **no**

### VIP

- price: **initially no**
- film: yes
- warranty: yes
- installation time: yes

### Liquidglass

- price: yes
- film: partial
- warranty: yes
- installation time: **no**

This became one of the strongest repeated findings.

---

## Pattern C - Meaningful-Response Delay

Liquidglass demonstrated that:

> an immediate autoresponder can hide a very slow meaningful response.

This suggests a distinct product metric:

> **Meaningful Response SLA**

---

## Pattern D - Sales Quality Varies Widely

Observed styles ranged from:

- generic bot
- canned information
- short Q&A
- detailed technical template
- consultative human sales
- active personalized follow-up

This suggests:

> **sales quality is inconsistent and likely depends heavily on the individual employee handling the conversation.**

---

## Pattern E - Good Human Sales Exists

KMQ demonstrated:

- qualification
- package tailoring
- value stacking
- payment-friction reduction
- social proof
- follow-up
- objection invitation

Therefore the goal should not be:

> replace human salespeople.

A stronger goal is:

> **standardize and amplify best-salesperson behavior.**

# 13. Product Requirements Validated by This Experiment

The observed evidence supports the following MVP requirements.

### 13.1 Message Context Extraction

Understand:

- vehicle
- model
- year
- service
- customer questions

before asking follow-up questions.

---

### 13.2 Question Completion Check

Track which customer questions remain unanswered.

Example internal alert:

> Customer asked about installation duration. Not answered.

---

### 13.3 Meaningful Response SLA

Track:

- auto-response time
- first useful response time

Do not consider generic bot messages a successful sales response.

---

### 13.4 Salesperson Copilot

Assist humans with:

- qualification
- response completeness
- product recommendation
- relevant examples
- objection handling
- next-step suggestions

---

### 13.5 Structured Follow-Up

Ensure open quotations do not disappear.

---

### 13.6 Manager Visibility

Show:

- waiting leads
- meaningful response time
- open quote value
- follow-up status
- salesperson performance
- conversion
